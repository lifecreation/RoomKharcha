ROOM KHARCHA - APP BANAO BINA ANDROID STUDIO KE

Is folder ki saari files (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) ek saath
GitHub repo mein upload karo (ek hi folder mein, sab ek saath).

STEP 1 - GitHub pe daalo
 1. github.com -> apne repo (jaise room-kharcha) mein jao -> "Add file" -> "Upload files".
 2. In 5 files ko drag-drop karo -> "Commit changes".
 3. Settings -> Pages -> Branch: main, folder: /(root) -> Save.
 4. 1-2 minute baad link banega: https://lifecreation.github.io/<repo-ka-naam>/

STEP 2 - Phone mein app install karo (dono dost)
 1. Phone ke Chrome mein wo link kholo.
 2. Upar kone mein teen dots (⋮) -> "Add to Home screen" / "Install app" -> Install.
 3. Home screen pe "Room Kharcha" ka icon aa jayega. Wahi se kholo, full-screen app jaisa chalega.

(schema.sql: Supabase SQL Editor mein ek baar chalana hai, agar pehle nahi chalaya.)

Bonus - agar sach mein .apk file chahiye (Play Store ke bina, WhatsApp pe bhejne ke liye):
 https://www.pwabuilder.com pe apna GitHub Pages link daalo -> Package for stores -> Android -> Download.
 Ye bina Android Studio ke APK bana deta hai.
